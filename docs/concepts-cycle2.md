# Cycle 002 — Concept Exploration

Date: 2026-10-26
Phase: research

Prior art (cycle 1): Orbit Duel (built), Gravity Flip Runner, Chrono Loop, Color Bind,
Signal Weaver. None re-proposed verbatim below except one deliberate evolution (#5).

## Candidates

1. **Tether Drift** — One-button grapple-swing arcade. A drifting probe holds/releases a
   tether to the nearest anchor; held tether = orbit, release = fling on tangent. Collect
   beacons, dodge drifting mines, endless score chase.
   Feasibility 5, Novelty 4, Scope 5 = 14
2. **Ink Tide** — Paint-flood territory game vs. rising tide; grid flood-fill logic.
   Feasibility 4, Novelty 3, Scope 4 = 11
3. **Echo Sweep** — Stealth where the player sees only sonar pings that fade.
   Feasibility 3, Novelty 4, Scope 3 = 10
4. **Seed & Siege** — Tiny tower-defense with plants growing on a timer.
   Feasibility 3, Novelty 2, Scope 3 = 8
5. **Orbit Duel AI** (evolution of Cycle 1) — adds a CPU opponent for solo play.
   Feasibility 5, Novelty 2, Scope 5 = 12 (addresses follow-up; low novelty)

## Selection: Tether Drift
Best score; pure 2D vector physics, single HTML file, one-button input (keyboard, mouse,
touch), skill ceiling from momentum conservation. Runner-up: Orbit Duel AI.
